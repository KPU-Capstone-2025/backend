Agent Data Flow
기업 에이전트 -> ALB -> OTel Collector
1
Data Ingestion HTTP POST
기업 서버의 에이전트가 리소스 수집 후
data.monittoring.co.kr:4318으로 전송
Header: X-Server-Group: {monitoringId}
2
L7 Intelligent Routing ALB :4318
ALB가 두 조건으로 라우팅 판단:
- Host Header == data
- X-Server-Group == {monitoringId}
해당 기업 전용 Target Group으로 포워딩
3
OTel Collector :4318
EC2 내 OpenTelemetry Collector 수신
URI 경로로 데이터 분류:
/v1/metrics -> Prometheus
/v1/logs -> Grafana Loki
4
Storage
